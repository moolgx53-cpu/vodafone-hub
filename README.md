# 📱 دليل باقات وأكواد فودافون مصر التفاعلي (PWA + تحديث تلقائي)

تطبيق ويب تقدمي متطور يعمل **100% بدون إنترنت (Offline-First)** ويتحدث **تلقائياً فورياً** على أي هاتف أو جهاز بمجرد قيامك بتعديل أي باقة أو سعر أو كود في المشروع.

---

## 🚀 كيف يعمل نظام التحديث التلقائي؟

1. **العمل بدون إنترنت (100% Offline):**
   - تم تزويد الأداة بـ `Service Worker` يقوم بتخزين كافة الأكواد والملفات والبيانات في الذاكرة التخزينية لجهاز المستخدم.
   - حتى لو انقطع الإنترنت تماماً، تفتح الأداة بسرعة البرق.

2. **فحص التحديثات التلقائي السحابي:**
   - في كل مرة يفتح فيها المستخدم الأداة من أي هاتف أو كمبيوتر (أو عند العودة لتبويب الأداة):
     - تقوم الأداة بفحص سريع وخفيف لملف `version.json` على السيرفر في الخلفية متجاوزة كاش المتصفح (`no-store`).
     - إذا وجد إصداراً جديداً (مثلاً `v1.0.2`)، يقوم الـ Service Worker فوراً بتنزيل التحديث في الخلفية وتحديث الكاش.
     - يظهر للمستخدم شريط إشعار علوي جذاب: **"⚡ يتوفر تحديث جديد للأداة!"** ويتم تحديث البيانات فوراً.

3. **تثبيت التطبيق (PWA):**
   - يمكن تثبيت الأداة كتطبيق رسمي على شاشة الهاتف الرئيسية (Android و iPhone) أو كبرنامج سطح مكتب على الكمبيوتر (Windows و Mac) من خلال زر **"تثبيت التطبيق"** بالأعلى.

## 🌐 خطوات رفع الأداة على رابط مجاني دائم (GitHub Pages)

لتصل الأداة لجميع الأجهزة وتتحدث تلقائياً، اتبع الخطوات البسيطة التالية لنشرها مجاناً مدى الحياة على **GitHub Pages**:

### الخطوة 1: إنشاء مستودع جديد على GitHub
1. افتح موقع [GitHub.com](https://github.com) وسجّل الدخول بحسابك (أو أنشئ حساباً مجانياً إذا لم يكن لديك).
2. اضغط على علامة **+** بالأعلى ثم اختر **New repository**.
3. اكتب اسم المستودع (مثال: `vodafone-hub` أو `voda`).
4. اختر المستودع **Public** ثم اضغط **Create repository**.

### الخطوة 2: رفع ملفات المشروع
يمكنك رفع الملفات إما بالسحب والإفلات من المتصفح أو عبر سطر الأوامر (Git):

#### الطريقة الأسهل (عبر المتصفح مباشرة):
- في صفحة المستودع الجديد على GitHub، اضغط على **uploading an existing file**.
- اسحب كافة ملفات المجلد `d:\voda` وضعها هناك:
  - `index.html`
  - `manifest.json`
  - `sw.js`
  - `version.json`
  - `vodafone-logo.png`
  - `vodafone-guide.pdf`
- اضغط على **Commit changes**.

#### أو عبر سطر الأوامر (Git):
```bash
git init
git add .
git commit -m "الإصدار الأول مع التحديث التلقائي ودعم PWA"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/vodafone-hub.git
git push -u origin main
```

### الخطوة 3: تفعيل الرابط المباشر (GitHub Pages)
1. من صفحة المستودع على GitHub، ادخل إلى **Settings** (الإعدادات).
2. من القائمة الجانبية، اضغط على **Pages**.
3. تحت قسم **Build and deployment**:
   - اضبط **Source** على **Deploy from a branch**.
   - اختر الفرع **main** والمجلد `/ (root)`.
   - اضغط **Save**.
4. خلال دقيقة واحدة، سيظهر لك الرابط الدائم في أعلى الصفحة باللون الأخضر، مثل:
   `https://YOUR_USERNAME.github.io/vodafone-hub/`

> يمكنك الآن مشاركة هذا الرابط مع أي شخص أو فتحه على هاتفك وجهاز الكمبيوتر!

## 🔄 كيف تقوم بتعديل أي شيء وتحديثه على جميع الأجهزة مستقبلاً؟

عندما تريد إضافة باقة جديدة، أو تعديل سعر، أو تغيير كود:

1. قم بالتعديل الذي تريده في ملف `index.html`.
2. افتح ملف `version.json` وزد رقم الإصدار، واكتب ملخص التعديل:
   ```json
   {
     "version": "1.0.2",
     "updatedAt": "2026-09-07",
     "changelog": "تحديث أسعار باقات فليكس الجديدة"
   }
   ```
3. في ملف `sw.js`، غيّر رقم الإصدار بالسطر 7:
   ```javascript
   const CACHE_VERSION = 'v1.0.2';
   ```
4. ارفع التعديل على GitHub (بالسحب والإفلات أو `git push`).

**النتيجة السحرية:**
بمجرد قيامك بالخطوة 4، أي شخص في أي مكان يفتح الأداة من هاتفه أو كمبيوتره سيتحدث تطبيقه تلقائياً لأحدث إصدار في ثوانٍ معدودة!
